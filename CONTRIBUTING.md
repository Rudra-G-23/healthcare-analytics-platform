**NAMING CONVENTION**

1. File and Folder Name
   1. Use Kebab-Case for Directories and General Files (e.g- `img-example.png`, `helper-folder-do-this-way/`)
   2. Use Snake_Case for code file and scripts
2. Branch Name
   Group by type using slashes to create logical namespaces, followed by hyphens.
   1. Features: `feature/login-page-styles`
   2. Bug fixes: `bugfix/header-alignment`
   3. Releases: `release/v2.1.0`
   4. Hotfixes: `hotfix/security-patch`
